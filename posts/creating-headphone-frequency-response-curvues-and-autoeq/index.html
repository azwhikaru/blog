手搓耳机频响曲线和适配 AutoEq

  • 2025-03-25
  • 默认分类

AutoEq 项目提供了很多耳机的频响曲线文件，但如果你的耳机不在此列，也可以通过频响曲线的图片手搓频响曲线和适配 AutoEq

频响曲线，就是下面图片这样的了。耳机的官网和商品详情页通常会有

以刚到手的 达音科 TITAN S2 为例。下面的频响曲线图片里标了完整的刻度，所以操作起来会比较容易

先要将图片上的数据转换成数字，可以使用 WebPlotDigitizer 这个工具。最新的版本是 V5，强制登录才可以使用，就用老版本 V4 了

先点击右侧的 Load Image 载入频响曲线的图片

类型保持默认的 2D (X-Y) Plot 即可

下面需要在图片上标出 4 个点

名称作用
X1标记 X 轴有效值起点
X2标记 X 轴有效值终点
Y1标记 Y 轴有效值起点
Y2标记 Y 轴有效值终点

频响曲线的 X 轴基本上都是 20 - 20kHz，这是人耳能听到的的频响范围

因此，X1 放在 X 轴起点，X2 放在 X 轴终点。X1 和 X2 应尽量在同一水平线上

Y 轴同理。Y1 放在 Y 轴有效值起点，Y2 放在放在 Y 轴的最大值就可以了。Y1 和 Y2 应尽量在同一垂直线上

标记完 4 个点后，点击右侧的 Complete!

在弹出对话框中输入 X1、X2、Y1、Y2 在图中对应的刻度。因为 X 轴的刻度分布是不均匀的，所以勾选 Log Scale

接下来，在右侧点击 Color 旁边的色块，选中曲线的颜色

点击右侧的 Run

程序会自动标注曲线上的点。如果点 数量太多、太少，或看起来不均匀，则可以在左侧菜单运行 Clear Data 后调整参数，再次标注。或者通过右侧工具栏手动微调每一个点

看起来自动标注的结果还不错

点击左侧菜单的 View Data。在弹出的对话框中设置 按照 X 轴升序排序 且 保留小数点后 2 位

点击 Download .CSV 导出曲线文件

进入 AutoEq 网站。选择搜索框右侧的 Open CSV file，选择刚才保存的曲线文件

在左侧菜单选择目标曲线，AutoEq 就会自动调整均衡器来匹配目标曲线

例如 Harman IE 2019。可以在中间的图表看到调节前后的差别

在右侧选择使用的均衡器 App，就可以直接导出预设了

是否变好听就见仁见智了。不过如果操作是正确的，应该起码不会变难听
