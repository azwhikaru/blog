Matebook E Go 2023 和 WOA 体验

  • 2026-03-14
  • 默认分类

一直想买一台轻薄、长续航的笔记本，要求不高，能独立处理简单的事务就可以，必要的话也可以用来远程主力电脑

最符合要求的似乎是 MacBook，最近苹果新出了 MacBook Neo

考虑过 Chromebook，Pixelbook Go 2018 的外观真的很喜欢，不过 Chromebook 配列键盘、超低压 CPU、完全没有性价比的二手价格还是劝退了

安卓平板，手上有 OPPO Pad 3 Pro，官方的键盘没有 Fx 功能区，安卓端 UU 远程的键盘输入也有点问题

然后我买了一台骁龙 8cx Gen3 的华为 Matebook E Go 2023

没有用过原生 Windows on ARM 的设备，很早在树莓派 3B 上用过 Windows 10，在魅族 16 和 MIX 2S 上也用过，第三方适配的 Windows on ARM 基本是玩具级别的

于是记录一下 2026 年在 Matebook E Go 2023 的骁龙 8cx Gen3 上使用 Windows on ARM 的体验

硬件

在闲鱼上花费 1.5K CNY 购得，配置是 16+512 GB

不知道能不能运行 Windows 平台的游戏，也没打算用这个玩游戏，所以 512 GB 大概是够的

拿在手上的感觉是不轻，机身 + 支架 + 键盘，用厨房秤称得重量 1.215 KG，只比 13 寸的 MacBook Air (1.24 KG) 和 Neo (1.23 KG) 轻一点

刚才发现这里打错了，于是马上打开休眠的电脑，一分钟就改完了，理想的使用场景

不轻，但机身是纯塑料的，塑料磨砂中框质感非常差，寨板都用金属机身

屏幕是 12.6 寸 2.5K 的触摸屏，发现用键盘 + 触屏来操作也不错，尺寸对于 Windows 来说不大不小。有 120 Hz，比 Chromebook 和 MacBook Air 赢太多

触摸屏响应也很不错

没有红外人脸，但有侧边指纹，识别率尚可，比起侧边指纹的手机还要好一些

键盘是普通的 Windows 配列键盘，到手已经油光锃亮，手感和普通笔记本键盘差不多，这篇东西就是在 Matebook E Go 2023 上打出来的。没有背光，没有 Page Up 和 Page Down，打字很不爽

扬声器和摄像头是听响和扫码的水平，话说 Windows 能扫码吗

软件

机器到手是 Windows 11 23H2 单语言版

在网上搜到开机按 F10 可以进入隐藏分区里的系统恢复功能恢复原厂镜像，一直报错，作罢

重新安装系统，并不是 PE 重装，是系统设置里的 “重新安装 Windows”，又下载 25H2 专业版镜像升级到专业版

用 Dism++ 备份了驱动，用 DiskGenius 镜像了隐藏分区备用

常用的软件里，有不少都提供了 Windows ARM 的构建

软件架构运行情况
PythonARM64原生支持
JavaARM64原生支持
Microsoft VS CodeARM64原生支持
Microsoft EdgeARM64原生支持
7-ZipARM64原生支持
TyporaARM64原生支持
GitARM64原生支持
TabbyARM64原生支持
Clash Verge RevARM64原生支持
OfficeARM64原生支持

其实本来不用 Clash Verge Rev，而是 Clash Party，因为 Clash Party 的 Windows ARM 构建会莫名挂掉，不知道是不是 Electron 干的。FlClash、LocalSend 这些基于 Flutter 的软件都没有 Windows ARM 构建

也有一些只能靠转译的

软件架构运行情况
IDA ProX64正常，动调正常
PixPinX64正常
网易 UU 远程X64正常，硬件加速正常
Notepad3X64正常

目前还没有遇到完全不能运行的软件

应该会有很多驱动不兼容，因为 Prism 转译层只能转译用户态程序，不过暂时没有装驱动的需求

续航

重负载掉电速度比预期得快，低负载符合预期

电池应该也有衰减，毕竟是 2023 年的东西

没用过超极本，比游戏本高到不知道哪里去了

嗯，好像就是一台普通的电脑，我还挺满意的，想到什么再补充

用这个能进星巴克办公吗
